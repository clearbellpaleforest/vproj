vproj — Vim Project Panel
=========================

A Vim9Script project navigation panel with file browsing, buffer management,
code project tree (from .vproj files), and quickfix list navigation.

Documentation:
  concept.md        — Design concept and specification (source material)
  install.md        — Installation instructions
  key-bindings.md   — Complete keyboard shortcuts
  design.md         — Behavioral specification
  architecture.md   — How the parts fit together
  constraints.md    — Hard boundaries
  decisions.md      — Design decisions and rationale
  manual.md         — User manual
  implementation-plan.md, implementation.md — Build order and notes
  test-plan.md, test-cases.md — Testing strategy and test vectors
  docs-pipeline.md  — How doc/ is published to the wiki
  index.md          — Wiki landing page (design decisions + document index)

  feedback/         — User feedback and suggestions (may be empty)
  revisions/        — Review notes and revision history
  phase-2/          — Phase-2 specs

Tests: ../tests/ (run with bash tests/run_all.sh)
Source: ../src/
Help file: ../src/doc/vproj.txt (:help vproj)
